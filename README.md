# Select Syndicate

Investor-facing marketing site for Select Syndicate (meetselect.com).

## Stack

- Next.js App Router + TypeScript + Tailwind CSS
- GSAP ScrollTrigger (parallax / sticky film chapter)
- Framer Motion (FAQ + CTA micro-interactions)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand notes

- Tokens match live Select Syndicate: `#0a0e14`, `#a9c9f7`, Select wordmark lockup.
- Typography uses **IBM Plex Sans** sitewide (institutional, no italic accents). Drop Select Sans `.woff2` files into `public/fonts/` if you want to swap the brand face later.
- Copy and legal language are preserved from the prior site; this repo is UI/UX only.

## Assets

Film, wordmark, and portfolio marks live in `public/assets/`.
